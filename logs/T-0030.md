## Self-audit — 2026-09-09T08:21:34Z

Whole branch, 2 commits / ~554 lines before the audit's own fixes: 6 source files,
3 test files, 5 documents, 1 task file. Scope from
`audit_scope.py scope --base main`.

**Seven findings, all fixed.** Three came from the sabotage sweep's survivors, which is
the pass that had to be run twice to be worth anything.

### 1. The exit rule was spelled twice (fixed, `e8c026c`)

`_check` and `_resolve` each carried
`EXIT_OK if evidence.stage_reached is Stage.COMPLETE else EXIT_REFUSED`. D7's objection to
a second command is that two commands which mostly agree is its own defect, and the
duplication was the mechanism by which they could stop agreeing — in the direction that
matters least visibly, a gate passing what the other command refuses. One
`_evidence_exit` now, and `test_check_and_resolve_cannot_disagree_about_the_exit_code`
over a passing project and a refused one.

### 2. Three prose claims outran their code (fixed, `e8c026c`)

`render_check` opened with "**A refused project prints no counts at all**" and then
described, two sentences later, the case where it does. `CheckedSurfaces` claimed a
conversion that could not be proven never reaches an IR — true of R009 and not of the
emit-time refusal that `currency_convert_refusal`, cited in the test beside it, actually
pins. And that test's own docstring said the compiler "refuses to *lower*" that
conversion; the fixture's header says the opposite in its first line: the refusal is at
emit, and the project resolves and passes guardrails.

Each was written while the code was still moving and none was re-read against what it
finally did.

### 3. The conversion walk could lose a mapping kind in silence (fixed, `e8c026c`)

`_conversions` asks each field for its `transform` with a default, because only a simple
mapping and a key carry a chain. Correct today and silent if it stops being: a recipe or
macro mapping that gained a chain would be walked past and the count would come out
smaller, with no other symptom. `test_only_a_simple_mapping_and_a_key_carry_a_transform_chain`
fails in the commit that adds one.

### 4. The machine output had no verdict, and the docs did not say so (fixed, `e8c026c`)

§3's sketch shows `{"status": "refused", …}`. What ships has no `status`, deliberately —
the verdict is the exit code and a key repeating it is a second answer that can disagree
— but nothing told a consumer reading a stored artifact what to read instead. The
scripting section now says: the stage, which carries more than a verdict would.

### 5–7. Three sabotage survivors, and what each one meant

The first sweep caught 8 of 11. Every survivor was a test asserting something true for a
reason other than the one it claimed.

```text
SURVIVED  no-ir-zeroes             SURVIVED  conversions-fields-only
SURVIVED  as-of-condition-dropped
```

**`no-ir-zeroes`** zeroed `_partial`'s no-resolution return. `_partial` has two IR-less
paths — a resolution that produced no IR, and no resolution at all — and every refusing
fixture in the corpus takes the first, because they all get past the resolve stage. The
test named "nothing is counted before an IR exists" was proving one branch and reading as
though it proved both. `BAD_REFERENCE` refuses at `RESOLVE` and is the only thing that
reaches the other.

**`conversions-fields-only`** dropped `mapping.key` from the walk. No fixture converts on
a key, so nothing moved — while the docstring asserted the key half was walked *because*
`resolve.build` walks it. A claim about behaviour with no test under it.

**`as-of-condition-dropped`** removed `if join.as_of is not None`. Counting every mart
join and counting the anchored ones are the same number on every fixture the parametrize
named, because the only fixture with joins in it had exactly one and it was temporal.
`ecom_basic` carries a join that is not, and is now the control.

Re-swept after the fixes: **11 of 11 caught, 0 survived.** Patch coverage 100% (41/41
added source lines), `just coverage` exit 0.

### Noted, not a defect

**§3's "warnings and advisories do not fail unless an explicit strict policy says so" is
built as vacuous truth.** Nothing in the compiler emits an advisory — RFC 0033's warnings
channel is still a draft — so there is no advisory for a strict policy to gate, and
building the policy now would be a flag with nothing behind it. The sentence becomes real
in the phase that gives it a subject.
